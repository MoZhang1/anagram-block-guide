# Anagram 单块图鉴

中文查阅网页：[打开图鉴](https://mozhang1.github.io/anagram-block-guide/)

资料快照：2026-09-27，KosmOS 1.18.0、Darkglass Suite 6.10.0。

中文说明修订：2026-09-28。保留原清单与参数快照，未变更插件授权或设备设置。

- 121 个原厂清单条目（不同箱体／艺术家 IR 单独列出，Mono/Stereo 按官方清单合并）。
- 97 个 Marketplace 扩展，含官方参数范围、默认值与原始选项。
- 15 个 Guitar Essentials 特别版参考条目，完整面板待核实，不代表普通设备自动解锁。
- 中英文／旧名／旋钮／用途搜索；分类、来源、获取方式与资料完整度筛选。
- 单块独立分享链接；复杂面板内搜索；可放大的真实单块图与商店图集。
- 参数区分功能、调节与听感、范围／默认值、资料依据。补充 1,000 余项调节说明；其中 144 项功能说明附厂商来源，其余按通用参考或待核实标注，不代表逐项获得厂商认证。
- 128 个条目支持面板图文定位，718 个参数关联 224 张参考图。严格匹配完整英文标签，不使用模糊词义匹配；缩略外观标识与操作面板分开标注。位置由图片文字识别生成，已抽查常用与多页面板，不能据此证明截图与当前固件完全一致。
- 响应式布局，纯静态页面，不连接设备、不收集用户数据。

## 红色图鉴界面

2026-09-28 更新：左侧使用 233 张按原图批量生成的低色数像素缩略图，右侧保留未处理原图。原图、面板热点和旋钮说明集中在同一个区域；较长的说明、数值、选项和来源可展开查看。手机采用目录／详情两屏切换。

收藏仅保存在当前浏览器，可筛选只看收藏；不上传或跨设备同步。方向键和 A／B 按键分别用于切换、查看和返回目录。编号由 `src/data/dex-numbers.json` 固定，未来新增条目应追加新编号，不重排已有编号。

首页默认显示合上的图鉴。点击“打开图鉴”播放约 0.86 秒的铰链翻盖动画，右上角“合上图鉴”可收起；同一次浏览中保留当前筛选、单块和收藏。有效的单块分享链接直接进入对应详情。开合按钮支持键盘，关闭时内部界面不参与焦点导航；系统开启“减少动态效果”时直接切换，不播放 3D 动画。

像素缩略图的生成脚本为 `scripts/build-pixel-thumbnails.py`（Python 3 + Pillow），输出 40×40 透明 PNG，保留原图宽高比例、最多 24 色，并在 `src/data/pixel-manifest.json` 记录原图 SHA-256。生成过程不覆盖原图。主界面使用自托管 Fusion Pixel 字体；授权与上游字体声明见 `public/fonts/`。界面为经典红色掌上图鉴的致敬设计，与宝可梦及其相关权利人无官方关联。

## 预设效果链

2026-10-05 新增独立「预设效果链」分区，沿用红色图鉴外壳、像素列表与清晰原图。

- 收录 **Darkglass Suite 6.11.0 自带的 36 条贝斯工厂预设**：271 个单块实例、1,269 项原始参数，包含 9 条双路预设与 17 个默认关闭的单块。
- 搜索名称、槽位、中文用途、链内单块；按用途和单路／双路筛选。点击链路节点定位参数，支持跳转已有单块介绍与独立分享链接（`#preset=factory-preset-01`）。
- 链路与参数来自官方应用随包数据；用途和调节建议为编辑分析，未经实机试听。具体歌曲／乐手原型在没有一手依据时标作「暂未查明」，不依据谐音认定复刻对象。
- 保留原始行、槽位和旁通状态；两行按设备行分开展示，不把并行误画成一条串联长链。仅展示基础状态，不包含场景、绑定或当前设备的修改。
- 数字保留原始精度，UI 最多显示 4 位小数，不自行换算物理单位或开关枚举。捕捉／箱体只引用文件名，不分发模型或 IR，也不凭文件名认定原型。
- 这是软件附带快照，**不是当前设备读取结果或所有固件的完整现行预设清单**。Guitar Essentials 和社区预设不在这一批范围内。

数据文件：`src/data/factory-presets.json`；逐条中文分析：`src/data/preset-notes.json`。来源记录包含 Suite 版本、核对日期和 `main.js` SHA-256。来源软件可在 [Darkglass Suite 官方页面](https://www.darkglass.com/pages/darkglass-suite) 获取；仓库不包含完整软件包。

维护者可用 `node scripts/extract-factory-presets.mjs <可信的官方 app.asar> <已核实的 Suite 版本>` 重新提取。脚本仅读取官方工厂贝斯数组，不访问账号、用户预设或设备；遇到目录结构／数量变化应先人工复核。新增资料须保留「官方确认／作者说明／根据链路推测／暂未查明」的证据边界。

## 资料依据与边界

1. [官方 1.18.0 清单](https://www.darkglass.com/pages/anagram-manual)确定原厂收录范围。
2. [官方 Marketplace](https://marketplace.anagram.shop/)公开产品列表、作者、产品图片和价格快照。
3. [MOD 官方插件服务](https://api.mod.audio/v2/lv2/plugins)提供 97 个扩展的 LV2 参数元数据。每个条目链接到具体版本的参数来源。
4. 已安装的 Darkglass Suite 6.10.0 的单块图片及内置面板种子数据，辅助原厂图片与参数名称核对。
5. [Anagram Answers](https://anagramanswers.com/categories/anagram-block-reference.18/)的面板记录辅助补齐原厂名称。**没有把该站标注为 ChatGPT 生成的原型介绍当作官方说明**，也没有把实体硬件的范围直接套到数字模型。原厂未验证数值不展示，来源明确标作社区。
6. [Guitar Essentials](https://www.darkglass.com/pages/anagram-guitar-essentials)只支持特别版条目的名称与用途；尚未核实的面板留空说明。

中文简介与旋钮解释为本项目辅助说明，非厂商认证译本；并非对专有 DSP 电路的完整说明。界面模式可能隐藏部分旋钮，固件更新也可能改变面板。价格仅为采集时标价，实际授权、税费和价格以商店为准。

具体功能优先参考厂商数字插件介绍／手册；实体 Darkglass 单块手册仅作功能参考，并明确区分实体规格与 Anagram 刻度。旧版手册、截图与当前元数据有差异时保留差异说明，不自动推定改名或等价。表中的“调节与听感”是编辑建议，不是推荐预设或实机试听结论。

## 图片与品牌

原厂图取自官方 Suite；扩展图取自官方商店。艺术家 IR 没有独立封面时使用系列共用箱体图并注明。所有图片、商标与产品名归各权利人所有，用于教育性辨识与引用，不对其作再许可。图片不是 AI 生成的替代品。本项目不是 Darkglass 官方网站，也不分发固件、付费插件、捕捉模型或商业 IR 音频。权利人如需纠正或移除图片，可通过仓库 issue 联系。

## 本地运行与部署

```sh
npm ci
npm test
npm run dev
```

`npm run build` 生成 `dist/`。GitHub Actions 在 `main` 更新时测试、构建并发布 Pages。基路径为 `/anagram-block-guide/`。

主要数据：`src/data/catalog.json`。初版辅助文本：`src/editorial.mjs`、`src/parameters.mjs`；后续修订优先使用 `src/guide-revisions.mjs`，执行 `node scripts/revise-guide.mjs` 应用并保留已有图文索引。新增图文索引可向脚本传入 OCR JSON，格式见脚本中的字段读取。发布数据采用静态快照，不会从商店自动更新未经核对的内容；未来更新需要重新比对官方清单、参数与图片。

新增／纠错应记录：单块名字、设备固件、英文面板名、截图或官方来源、中文说明。请勿上传个人预设、账户信息或授权文件。
