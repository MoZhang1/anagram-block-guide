# Design specification

Source concept: exec-3a58d5ce-8fd4-4ddc-8a6e-f5e5319e587b.png, generated for this task.

White reference workspace; forest green #28594b selection; ink #17201e; muted #69736f; rules #e4e9e6. No marketing hero or decorative cards.

Desktop: compact 64px header, 72px search row, 210px category rail, 330px result list, flexible detail pane. At 1100px rail narrows to 180px, list to 280px. At 760px filters collapse above list, detail replaces list with a back action.

Typography: system sans / PingFang SC / Microsoft YaHei. Title 26px; detail title 32px; body 15px/1.75; labels 13px. 8px spacing rhythm. Real controls are text/table, not fake functional knobs. Source images use contain, never cropped.

Intentional deviations from generated concept: accurate names/categories/counts replace invented concept data; actual in-app block artwork replaces fake physical product imagery; metadata confidence, update date, free/paid filter and image gallery serve the requested reference task. Special-edition content, if included, is clearly separate from ordinary firmware.
